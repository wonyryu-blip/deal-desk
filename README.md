# Deal Desk

비상장 투자 운용역을 위한 기업 중심 대시보드와 보고서 도서관입니다.

## 사용법

`dist/index.html`을 다운로드해 브라우저로 열거나 비공개 호스팅 주소를 사용하세요. 별도 설치나 외부 라이브러리가 없습니다.

1. 기업 등록: 기업 소개, 산업, 투자 단계, 담당자와 투자 논리를 입력합니다.
2. 기업명을 클릭하고 투자 딜을 등록합니다. 같은 기업에 복수 조합·딜을 연결할 수 있습니다. 금액 단위는 억원입니다.
3. 노트 / 보고서에서 본문 작성, HTTPS 원문 링크, 20MB 이하 파일 첨부를 지원합니다.
4. 대시보드에서 기업·조합·단계로 검색하고 전체 도서관에서 자료 유형·본문으로 검색합니다.
5. 백업 내보내기로 첨부파일을 포함한 JSON을 안전한 곳에 보관합니다. 다른 브라우저에서 불러올 수 있습니다. 불러오기는 기존 자료를 교체합니다.

## 데이터 보관

- 실제 기업자료는 현재 브라우저의 IndexedDB에 보관됩니다. GitHub나 서버에 자동 업로드/동기화하지 않습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기/주소 사용 시 기존 기록을 사용할 수 없을 수 있습니다. 정기 백업이 필요합니다.
- 공개 저장소에는 프로그램 코드만 보관하세요. 실제 투자자료와 백업 JSON을 커밋하지 마세요.
- 이 버전은 개인 브라우저 보관형입니다. 팀 공동 편집, 서버 백업, 접근 권한별 자료 분리는 지원하지 않습니다.
- 가상 예시는 사용자가 버튼을 누른 경우에만 추가됩니다. 실제 기업이나 투자 실적이 아닙니다.
- 투자액은 투자완료·회수진행·회수완료 딜의 입력금액 합계이며 현재 잔액이나 공정가치가 아닙니다.

## 개발

정적 HTML/CSS/JavaScript. `dist/index.html`이 전체 앱입니다. 브라우저에서 HTML/JS를 실행하는 첨부파일 인라인 미리보기는 제공하지 않으며 파일은 다운로드하여 열도록 구성했습니다.
